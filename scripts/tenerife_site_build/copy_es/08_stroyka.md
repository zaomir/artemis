# Nueve etapas desde el terreno hasta las llaves, con informes semanales

Seleccionamos una parcela para veinte residencias en La Quinta, Santa Úrsula. Tras elegirla afinaremos el programa. El modelo financiero prevé @months@ meses desde el pago completo hasta la salida en efectivo.

[КАДР F15]

### Nueve etapas de obra

| Etapa | Resultado |
|---|---|
| 1. Terreno | Parcela preparada |
| 2. Cimentación | Base y zócalo terminados |
| 3. Estructura | Muros y forjados |
| 4. Cubierta | Tejado y paneles |
| 5. Instalaciones | Agua, electricidad y clima |
| 6. Fachada | Revoco, ventanas y terrazas |
| 7. Interiores | Acabados, cocinas y baños |
| 8. Piscina | Zona común climatizada |
| 9. Exterior | Caminos, accesos y jardines |

[КАДР F14]

### Hitos del modelo financiero

| Mes desde el pago completo | Evento del escenario base |
|---|---|
| 0 | Fondo inicial completo y compra del terreno |
| 3–30 | Firma de veinte contratos de compradores |
| 8 | Cimentación: pagos acumulados del 70% |
| 18 | Estructura: pagos acumulados del 80% |
| Hasta 33 | Obras principales y reserva presupuestada pagadas |
| 36 | Liquidación de compradores y salida de inversores |

Es el calendario previsto del modelo. Las fechas reales dependen de la parcela, el proyecto y las ventas.

[КАДР F16]

### Qué recibe cada semana

Obras realizadas, importes pagados, cobros de compradores y saldo del proyecto. El registro sigue: fecha → etapa → resultado → siguiente paso.

Vea cómo el dinero se convierte en cimientos, cubierta y vidrio. Los informes al inversor siguen hasta la liquidación; al comprador, hasta la entrega.

[КАДР F17]

### Quién dirige la obra

Boris Ribaut supervisa estructura, obra e informes. Simon Subic dirige parcela, lanzamiento y financiación. [Perfiles y responsabilidades](/tenerife/equipo/).

[КАДР F18]

### Cómo se pagan los trabajos

El capital inicial y los pagos por hitos cubren el presupuesto. El modelo base no incluye capital adicional del promotor ni crédito bancario. Cada contrato fija el precio al firmar; el crecimiento se aplica solo antes.

[КАДР F12]

### Si cambia el calendario

Los retrasos de ventas y mayores costes deben reflejarse en el flujo de caja actualizado. Cada etapa necesita una fuente de pago. [Financiación y sensibilidad](/tenerife/inversores/#funding).
