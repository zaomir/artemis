# Una casa para usar a su manera

Vivir todo el año, pasar el invierno o alquilar a largo plazo: decide el propietario. La inversión Artemis termina con una salida en efectivo y no contempla pagos anuales de alquiler.

[КАДР F10]

### Para vivir

Salón luminoso, terraza, climatización inteligente y piscina climatizada. Elija superficie: [48 a 100 m²](/tenerife/producto/).

[КАДР F04]

### Para alquilar a largo plazo

Los futuros inquilinos compararán distribución, mantenimiento y acceso a la ciudad. Antes de comprar, consulte anuncios actuales de viviendas equivalentes y cuente periodos vacíos, mantenimiento y reparaciones. El alquiler cobrado no equivale al ingreso tras gastos.

[КАДР F05]

### Para el inversor

El nuevo modelo no conserva una cartera de alquiler para pagos anuales. El inversor paga íntegramente y recibe efectivo al vender o recomprar su participación. Objetivo: @target@% anualizado durante @months@ meses. [Modelo de inversión](/tenerife/inversores/).

[КАДР F03]

### Solicitar un cálculo

Diga al equipo si busca vivienda para vivir o alquilar. Prepararemos el cálculo de compra; la inversión con salida en efectivo se calcula aparte.

**Кнопка: «Solicitar un cálculo»**
