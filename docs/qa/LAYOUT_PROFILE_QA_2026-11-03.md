# Tenerife — section spacing and illustrated profiles

Founder request: check spacing and text composition on every page, including “Calculate your area”; place
Simon/Boris photographs beside relevant section copy; horizontal photo strips only for portfolio cases;
different clothing, expression, pose and situation in each person's published photographs.

## Layout changes

- Embedded calculator is a group inside the investor section, with no second section padding. Its controls and
  results follow the page gutters: 20 px at 320, 56 px at 1440. The standalone tool retains its section wrapper.
- Calculation introduction is text-only. Its unrelated roofing photo now belongs to the solar/energy section.
- Shared text/image rows align from the top. First tables and last content blocks no longer add accidental
  outer margins; paragraph wrapping uses the existing reading measure, fonts and colors.
- Profiles have a portrait beside the introduction, followed by three separate photo/text stories. Plain
  profile sections use the existing tighter spacing token. Empty photo-slot bars are omitted on these pages.
- Boris's former introductory pool picture accompanies the handover/specification text, which discusses the pool.
- The two residence photographs each accompany their own paragraph instead of sitting together in a gallery.
- Portfolio cases remain manually scrollable horizontal strips, with spacing between the cards.
- An inline source link on English Impressum no longer behaves as an inline flex box that pushes past its text column.
